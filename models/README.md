Keep these user-supplied GLB files in this folder (the names are case-sensitive):

- `animal_company_-_boombox.glb` — catalog ID `item_boombox`
- `animal_company_-_company_ration.glb` — catalog ID `item_company_ration`
- `animal_company_-_crate.glb` — catalog ID `item_crate`
- `animal_company_-_rubberducky.glb` — catalog ID `item_rubberducky`
